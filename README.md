# dsh-superagent-demo
Playground repo for dsh-superagent: a proactive agent for one GitHub repository

## Getting started

This is a public playground repository for practising with dsh-superagent, an agent that proactively works on a single GitHub repository.

Clone it locally:

```bash
git clone https://github.com/hehy-bot/dsh-superagent-demo.git
cd dsh-superagent-demo
```
